# 📸 FakeInsta (React App)

Cześć! To jest kod źródłowy aplikacji **FakeInsta** – wiernego klona popularnego serwisu społecznościowego Instagram, stworzonego przy użyciu biblioteki **React**.

Projekt powstał w celach edukacyjnych oraz praktycznych, aby przećwiczyć budowę komponentową, zarządzanie stanem aplikacji oraz stylowanie nowoczesnego interfejsu (UI).

---

## 🚀 Co znajduje się w aplikacji?

* **Ekran główny (Feed):** Strumień postów z awatarami, nazwami użytkowników, zdjęciami oraz przyciskami interakcji.
* **Interaktywne funkcje:** 
  * Lajkowanie postów (reakcja serduszka w czasie rzeczywistym).
  * Dodawanie i przeglądanie sekcji komentarzy.
* **Sekcja Relacji (Stories):** Górny pasek z kółkami relacji na wzór oryginalnej aplikacji.
* **Profil użytkownika:** Podsumowanie informacji o koncie, licznik postów/obserwujących oraz galeria kafelkowa zdjęć.
* **Komponentowość:** Cały interfejs został podzielony na mniejsze, rewalidowalne komponenty Reacta.

---

## 🛠️ Użyte technologie

* **React (JSX)** – biblioteka do budowy interfejsu użytkownika w oparciu o komponenty.
* **JavaScript (ES6+)** – logika aplikacji i zarządzanie stanem.
* **CSS3 / Styled Components** – nowoczesne style i responsywny wygląd (RWD) dostosowany do urządzeń mobilnych oraz desktopów.
* **Vite / Create React App** – środowisko uruchomieniowe i budujące projekt.
